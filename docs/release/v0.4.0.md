# net-io v0.4.0 - Extended

**Behind a proxy, on a Unix socket, over UDP, started by systemd, and restarted without closing the port.** v0.4.0 adds the edges a real deployment meets around the TCP core of 0.3: the PROXY protocol, the TLS seam on listeners, Unix domain sockets, UDP with an amplification guard, inherited listeners, and listener hand-off between processes.

## What is net-io?

The network IO substrate for the `-io` and `-net` crates: listeners and sockets, the life of each connection, the limits and timeouts around it, graceful drain and restarts, and the seams a connection gate and a TLS engine plug into. It is protocol-free and has no runtime dependencies; the few OS calls `std` does not expose go through the crate's own small, tested FFI layer.

## What's in 0.4.0

- **Behind a proxy.** PROXY protocol v1 and v2 with a strict parser, every TLV, and CRC32C. A listener that requires the header trusts only the proxies configured for it and closes anyone else before reading a byte; the real client address then drives the caps, the gate, and the logs. Tested in CI behind HAProxy (v1 and v2) and nginx, over TCP and over a Unix socket.
- **TLS on listeners.** Plug in a TLS engine (tls-net) and turn TLS on per listener. Reads return plaintext, the gate still sees every write, and graceful closes send `close_notify`.
- **Unix domain sockets.** The socket file is mode 0600 and gets its mode before it listens, so nothing connects under the umask's permissions. Stale files are cleaned up only when nothing listens on them; the server sees each peer's process, user, and group; descriptors can be passed with bytes.
- **UDP that cannot be turned against others.** Every datagram is charged to its source's budget; replies to a source that has not proved it can receive are never larger than what it sent; truncated datagrams are reported, never silently cut.
- **Restarts without a closed port.** Start from systemd socket activation or as a FastCGI child, add and remove listeners on a running server, and hand listening sockets to a new process: the new one opens its door before the old one stops, and a test with two processes under about 1,000 connections per second refuses none.
- **Back-channels under the gate.** Register a dialed connection with a server (`Server::adopt`) or a gate (`set_gate`), so outbound connections can be revoked like accepted ones.

## Security

`docs/SECURITY.md` is new: the threat model, 45 threats with their defence, cost, and the test that attacks them, and what net-io does not cover. The parsers that read untrusted bytes (PROXY, the hand-off manifest, the systemd environment, CIDR and trusted-proxy lists) are fuzzed in CI.

## Performance

The new transports share one connection core with TCP; the per-round-trip cost of a TCP echo is unchanged against a bare `std` server (within 1% on the 0.4 benchmark run). The 0.3 baselines in `docs/PERFORMANCE.md` still hold.

## Platform notes

Unix sockets, descriptor passing, inheritance, and the hand-off are Unix in 0.4; Windows gets named pipes, AF_UNIX, and its own hand-off in 0.5. On Windows, UDP sockets switch off `SIO_UDP_CONNRESET`, so an ICMP report never fails a receive. Details for every platform are in `docs/PLATFORM-NOTES.md`.

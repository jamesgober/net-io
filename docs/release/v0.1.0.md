# net-io v0.1.0 - Scaffold

**The repository and the plan.** v0.1.0 sets up the crate in the portfolio template and writes down the design before any code: what net-io owns, what it deliberately leaves to other crates, and how the layers above it plug in. There is no functional code in this release.

## What is net-io?

The network IO substrate for the `-io` and `-net` crates: listeners and sockets for TCP, UDP, Unix domain sockets, and Windows named pipes, connection lifecycle, limits and timeouts, graceful drain, the PROXY protocol, and the seams for TLS and a connection gate. It is protocol-free, so the same transport serves HTTP (through `http-net`), WebSocket (through `ws-net`), a database wire protocol, or a consensus transport.

## What's in 0.1.0

- The crate manifest: edition 2024, MSRV 1.85, no dependencies, `Apache-2.0 OR MIT`.
- CI on Linux, macOS, and Windows, on stable and 1.85, plus `cargo audit` and `cargo deny`.
- `dev/PLAN.md`: scope, architecture, deployment modes, security responsibilities, ecosystem, open decisions, and the decision log.
- `dev/DIRECTIVES.md` (engineering law and definition of done) and `dev/ROADMAP.md` (phases with exit criteria).

# net-io v0.2.0 - Design Lock

**The API, written down before the code.** v0.2.0 locked the public API of net-io from `0.3.0` to `1.0.0`: every type, trait, function, error, limit, and default, with the version that ships each one. There is still no functional code in this release; `0.3.0` brings TCP with the blocking driver.

## What is net-io?

The network IO substrate for the `-io` and `-net` crates: listeners and sockets for TCP, UDP, Unix domain sockets, and Windows named pipes, the life of each connection, the limits and timeouts that stop a peer from holding what it should not, graceful drain and zero-downtime restarts, the PROXY protocol, and the seams a connection gate and a TLS engine plug into. It is protocol-free and has no runtime dependencies.

## What's in 0.2.0

- `docs/API.md`: every public item with its signature, behaviour, errors, cost target, and examples, graded P0 to P3 and sorted into three tiers. The simplest uses are one call each: `net_io::serve(addr, handler)`, `net_io::connect(addr)`, `net_io::listen_local(name)`.
- The gate seam was settled as one `Gate` trait. Admission returns a per-connection ticket that net-io hands back before every write and once more at close with the close reason, so a check needs no lookup and the gate learns how every connection ended.
- The TLS seam was settled as an in-place session: ciphertext is decrypted inside the connection's own read buffer and plaintext is encrypted straight into the output buffer. The condition for this shape (rustls reassembling multi-record handshake messages in the caller's buffer) was checked against the rustls 0.23.46 source.
- `dev/SYS-SURFACE.md` listed every OS function, constant, and struct the crate will declare per platform, with the documentation each relies on. net-io keeps zero runtime dependencies: `libc` and `windows-sys` are used only as dev-dependencies to cross-check the declarations in CI.
- `dev/PLAN.md` recorded the requirements, the architecture, 45 threats each with its defence, test, and cost, the performance targets, 132 edge cases, platform experiments on Windows and Linux, and decisions D-013 to D-050.
- `dev/ROADMAP.md` followed the portfolio's version table: core (0.3), extended (0.4), feature complete with the reactor (0.5), optimisation (0.6), hardening (0.7), alpha (0.8), beta (0.9), stable (1.0).
- Names were changed to full words before anything was published (`TcpConnection`, `ConnectionInfo`, `SessionContext`).

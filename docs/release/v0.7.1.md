# net-io v0.7.1 - Patch

**Idle TLS connections on the reactor give back their output buffers.** No API change; every 0.7 program builds unchanged.

## What is net-io?

The network IO substrate for the `-io` and `-net` crates: listeners and sockets, the life of each connection, the limits and timeouts around it, graceful drain and restarts, and the seams a connection gate and a TLS engine plug into. It is protocol-free and has no runtime dependencies.

## Fixed

**Upgrade if you serve TLS on the reactor.** After a reply, an idle TLS connection kept its session's output with the spare buffers of that reply: up to four 16 KiB buffers, charged to the server's shared buffer budget. A plaintext connection gives them back as it starts to wait; a TLS connection gave back its two TLS buffers (new in 0.7.0) but not these. With enough connections that each fetched a large reply and then went idle, the budget ran out and other connections' writes failed. tls-net measured about 42 KB per warm idle connection; a TLS connection now gives these buffers back as a plaintext one does. 0.6 held these buffers too, along with 128 KiB of TLS buffers per connection.
